# \# Gas-dynamics-model

# 

# MATLAB code for modelling gas kinetics in diving beaked whales.

# 

# \## Current status

# 

# This repository contains a legacy version of a model that has been developed and modified over several years. The original files are preserved in:

# 

# &#x20;   legacy/2026-10-12-original/

# 

# The current development branch is being used to document, reorganize, and revise the model.

# 

# \## Main entry point

# 

# The current apparent driver script is:

# 

# &#x20;   driver\_to\_beakedwhale\_tissue\_kin.m

# 

# This calls the main simulation function:

# 

# &#x20;   beakedwhale\_tissue\_kinetics1.m

# 

# \## Input data

# 

# The model expects whale-specific dive and summary CSV files. These files are not currently included in the repository.

# 

# \## Development plan

# 

# 1\. Map the existing functions and data flow.

# 2\. Confirm that the original model can still be run.

# 3\. Separate input data, model functions, analysis scripts, and outputs.

# 4\. Implement and test the planned model modification.

# 5\. Compare revised results with the legacy model.
